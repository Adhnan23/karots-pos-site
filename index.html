How it runs

Deploy once, on your own hardware

  • One self-contained static binary — assets and DB migrations embedded, CGO-free.
  • PostgreSQL as the only external dependency.
  • One-shot installers: install.sh (Linux), install.ps1 (Windows).
  • Chromium kiosk auto-start for a dedicated till machine.
  • Multiple terminals share one server over the LAN.
  • Runs on cheap hardware, including old PCs.
  • White-labelable — colours, receipt style, card shape and density are per-shop config, not a fork.
