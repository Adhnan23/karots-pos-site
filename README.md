# Karots Suite site

The public site for Karots Suite: what it does, the phone tour sellers show at a shop, the guides and plugin
pages (synced from the Suite repo), pricing and contact. Static Astro build, deployed to Cloudflare Pages.

The old Karots POS site lives on the `archive/karots-pos` branch.

```sh
bun install
bun run dev      # http://localhost:4321
bun run test     # build + checks on the built pages
bun run check    # types
```
